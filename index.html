Mystery Meal

Web App — Personal Project

Mystery Meal lets you select ingredients you already have at home and instantly shows real recipes you can make. It also highlights which additional ingredients you’d need to complete each dish, helping you cook with less waste and fewer trips to the store.

To‑Do List

Web App — Personal Project

A simple to‑do app where you can create tasks, organize them into lists, and view them in a calendar. It focuses on clear structure and easy daily planning, so you can quickly see what’s due and keep track of your progress.

Dance Inventory System

Diploma Thesis — Prototype

A prototype system for dance groups to manage costume and prop inventory by scanning QR codes attached to each item. Items can be assigned to specific dancers, allowing teachers to track where each piece is, how many there are, and which groups or performances they belong to.
